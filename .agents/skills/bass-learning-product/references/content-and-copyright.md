# 教学素材与版权发布规则

## 不可违反的规则

1. 不删除第三方乐谱、Guitar Pro、音频或视频中的作者、来源、版权信息或水印。
2. 不通过裁剪、遮挡、重绘、转码或重新排版隐藏权利人信息。
3. 文件可以下载不等于可以复制、修改或重新公开发布。
4. 无法从当前材料确认授权时，标记“授权不明”，不得猜测为可用。
5. 授权不明的素材不得进入公开部署目录，也不得作为产品核心内容展示。
6. 保留许可要求的作者署名、许可证名称、来源链接和修改说明。

## 素材状态清单

为每个乐谱、GP、音频、视频或基于歌曲的教学素材记录：

| 字段 | 要求 |
| --- | --- |
| 素材名称 | 用户可识别的名称 |
| 素材类型 | PDF、GP、音频、视频、图片或其他 |
| 作者/权利人 | 原作者、编配者、录音权利人等；未知则明确写未知 |
| 来源 | 原始页面或取得文件的渠道 |
| 授权状态 | 原创、已授权、公有领域、开放许可、仅外链、授权不明 |
| 许可依据 | 授权文件、许可证、公开条款或无法确认 |
| 署名要求 | 发布时必须显示的文字和链接 |
| 修改权限 | 是否允许改编、裁剪、转码或商业使用 |
| 公开处理 | 可托管、仅外链、替换或从公开目录移除 |

## 状态判定

- **原创**：由本站团队独立创作，并能说明作者与创作记录。
- **已授权**：权利人明确许可本项目按目标方式使用；保存许可范围和证据。
- **公有领域**：确认作品及相关编配、录音分别不受版权限制；不能只看原曲年代。
- **开放许可**：记录具体许可证版本，并遵守署名、相同方式共享、非商业或禁止演绎等条件。
- **仅外链**：本站不托管文件，只展示必要歌曲信息并链接至权利人或合法平台。
- **授权不明**：来源、作者或许可范围不能确认；默认不可公开托管。

## 可接受的替代方式

- 使用自己创作的技术练习。
- 使用获得明确许可的乐谱或录音。
- 使用经确认的公有领域或开放许可素材。
- 只显示歌曲信息、训练目标和难度，跳转到合法来源。
- 使用抽象节奏型、通用和弦进行和原创 Bass line 教学。

## 原创练习库优先级

优先制作 4–16 小节、目标单一、容易验收的原创练习，例如：

- 八分音符稳定性；
- 根音连接；
- 左右手闷音；
- 切分节奏；
- 和弦音选择；
- 经过音应用。

每条练习应记录目标能力、难度、建议速度、练习方法、通过标准、作者和授权状态。不要复刻一整首商业歌曲来规避授权判断。

## 发布前检查

1. 对公开目录中的每项素材建立清单。
2. 逐项核对作者、来源、许可范围与署名要求。
3. 将授权不明素材移出公开部署范围，或改成合法外链。
4. 检查页面、文件元数据和下载入口是否保留必要署名。
5. 抽查公开构建产物，确认被移出的文件无法通过旧链接继续访问。
6. 无法确认法律结论时，明确说明“无法从当前代码或材料确认”，并建议向权利人或专业法律人士核实。
